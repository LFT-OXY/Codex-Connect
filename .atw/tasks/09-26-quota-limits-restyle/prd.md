# 订阅额度样式重做

**Status:** ready-for-agent

## Problem Statement

用户在「设置 → 账号」页查看 Codex、Claude Code、Grok、agy 的订阅额度。数据是全的，但展示是一张「账号 / 5 小时 / 7 天 / 用于 Harness」表格：模型专属窗口、月额度挤在账号信息下方，重置卡藏在一个展开入口里，看不出「按现在的速度是否用得太快」。用户日常使用的 TokenTracker「限额」页把同样的信息画成按 Harness 分组的横条，一眼就能看清每个窗口用了多少、离重置还有多久、是否超出节奏，用户觉得当前页面不好看、不好读，希望改成那种样式。

## Solution

把账号页的额度展示改成按 Harness 分组的横条列表：

- 每个账号一组，组头是产品 Logo、账号名称（邮箱/名称）与套餐等次级信息。
- 组内每个额度窗口一行：左侧窗口名（5h、7d、模型专属如 Fable、月额度等），中间一条横条，右侧百分比与距重置的剩余时间。
- 可推算时间进度的窗口，在横条上画一根节奏标记，表示「如果匀速使用，此刻应当用到的位置」；实际用量明显超出节奏时标记变为警示色。
- Codex 组下方逐张列出重置卡，每张一条横条表示剩余寿命，右侧显示到期时间。
- 工具栏保留搜索、已用/剩余切换和刷新；「Pi 中的账号」专区与导入到 Pi 的入口保持现有行为。

数据链路、缓存与刷新语义不变；除重置卡需要补充发放时间外，不新增数据来源。

## User Stories

1. 作为订阅用户，我想让每个账号的额度窗口以横条显示，以便一眼看出用了多少。
2. 作为订阅用户，我想让同一账号的所有窗口（5 小时、7 天、模型专属、月额度）纵向排在同一组里，以便比较同一账号的不同限制。
3. 作为 Claude Max 用户，我想看到 Fable 这类模型专属周窗口与 5h、7d 并列，以便知道某个模型的独立额度。
4. 作为订阅用户，我想在每条横条右侧看到百分比，以便得到精确数字。
5. 作为订阅用户，我想在百分比旁看到距离重置的剩余时间（如 `1h`、`3d`），以便知道多久后恢复。
6. 作为订阅用户，我想悬停剩余时间时看到完整的本地重置时间（含日期、时区），以便精确安排工作。
7. 作为订阅用户，我想在 5 小时和 7 天窗口上看到节奏标记，以便判断按当前速度是否会提前用完。
8. 作为订阅用户，我想在实际用量明显超过节奏时看到标记变成警示色，以便及时放慢使用。
9. 作为订阅用户，我想在用量很低时不被节奏标记打扰，以便页面保持简洁。
10. 作为订阅用户，我想让横条颜色随已用比例变化（70% 起警示，90% 起强调），以便快速发现快用完的窗口。
11. 作为订阅用户，我想继续在「已用」和「剩余」两种口径之间切换，并让横条、数字、节奏标记同步切换口径，以便按习惯阅读。
12. 作为订阅用户，我想让风险颜色始终按已用比例判断，与展示口径无关，以便颜色含义稳定。
13. 作为 Codex 用户，我想在 Codex 组下看到每张重置卡一条横条，以便知道各张卡还剩多久过期。
14. 作为 Codex 用户，我想在每张重置卡右侧看到其到期的本地时间，以便在过期前安排使用。
15. 作为 Codex 用户，当接口没有提供某张卡的发放时间时，我想仍然看到该卡及其到期时间，只是不画寿命横条，以便不看到编造的比例。
16. 作为 Codex 用户，没有重置卡时我不想看到任何重置卡区域或「0 张」，以便不被误导。
17. 作为订阅用户，我想点击刷新按钮重新查询所有账号额度并绕过短期缓存，以便看到最新数据。
18. 作为订阅用户，我想在刷新过程中看到各 Harness 的结果先到先显示，以便不必等最慢的一个。
19. 作为订阅用户，我想继续用搜索框按邮箱、名称、Agent 或套餐筛选账号组，以便在多个账号中定位。
20. 作为 Grok 用户，我想让 Grok 的周/月额度和产品用量也以同样的横条样式出现，以便所有 Harness 风格一致。
21. 作为 agy 用户，我想让 agy 的模型组窗口以横条样式出现，以便与其他账号对齐阅读。
22. 作为订阅用户，缺少某个窗口时我不想看到补成 0% 或 100% 的横条，以便不被错误数据误导。
23. 作为订阅用户，我想让窗口到点后显示「待刷新」而不是自动归零，以便知道数据需要刷新。
24. 作为订阅用户，我想让剩余时间每分钟和页面重新获得焦点时自动更新，而不重新查询额度，以便倒计时准确又不浪费请求。
25. 作为订阅用户，我想在账号组头部看到套餐标识（如 Pro 5x/20x、Max），以便确认当前订阅。
26. 作为使用 Pi 导入功能的用户，我想让 Codex 和 Grok 组上仍然有导入到 Pi 的小图标，以便继续使用该功能。
27. 作为使用 Pi 导入功能的用户，我想让「Pi 中的账号」专区保持现有行为，以便已有配置不受影响。
28. 作为窄窗口用户，我想让横条列表在窄宽度下依然可读、不出现横向滚动，以便在小窗口中查看。
29. 作为深色/浅色主题用户，我想让横条、节奏标记和文字在两种主题下都清晰，以便任何主题下都可读。
30. 作为使用辅助技术的用户，我想让每条横条可被读出窗口名、已用/剩余百分比和重置时间，以便无障碍使用。
31. 作为中文或英文界面用户，我想让所有新文案都有对应语言版本，以便界面语言一致。

## Implementation Decisions

- **改造范围**：仅替换账号页中额度的呈现（原表格及其列头），保留工具栏（搜索、已用/剩余切换、刷新）、账号身份与套餐信息、Pi 导入入口与「Pi 中的账号」专区。Composer 额度药丸与弹层不动。
- **数据来源不变**：Codex 额度仍来自 Host 的 Codex 账号额度请求，其他 Harness 仍来自 `codexhost/harness/accounts/sources` / `inspect`；并行加载、先到先显示、15 秒缓存、刷新绕过缓存等语义不变。
- **窗口行的统一视图模型**：把 `AccountCreditsSnapshot` 的主窗口与 `productUsage[]` 统一投影为「窗口行」列表：窗口名、已用百分比、可选重置时间、可选窗口总长。窗口总长只在语义明确时给出：`five_hour` = 5 小时、`seven_day`/`weekly` = 7 天；模型专属周窗口仅当来源明确为周窗口时给 7 天；`monthly`、`unknown` 与无法判定长度的产品用量不给窗口总长。
- **节奏标记**：纯函数计算。标记位置 = (窗口总长 − 距重置剩余时长) / 窗口总长，限制在 0～100%。仅当窗口总长与重置时间都存在、且已用 ≥5% 时显示。实际已用超过标记 3 个百分点以上为警示色，否则为常规色。「剩余」口径下标记位置与横条同步镜像。
- **颜色阈值**沿用现有产品规则（已用 70% 起警示、90% 起强调），与展示口径无关。
- **剩余时间格式**：沿用现有倒计时组件的规则与每分钟/重新聚焦刷新机制；截图中的单单位短格式（`1h`、`3d`）与现有两单位格式（`6d17h`）的取舍，按现有产品文档规则保留两单位格式，除非实现时发现与样式冲突再回到规格讨论。
- **Codex 重置卡**：在重置卡契约中为每张卡补充可选的发放时间，由 Host 解析官方重置卡响应时一并读取。寿命横条长度 = 距到期剩余时长 / (到期 − 发放)。缺少发放时间的卡只显示到期时间、不画横条。继续不提供「使用重置」、不调用消耗接口。
- **契约变更**：`accountResetCreditsSchema` 增加按卡排列的明细（每张卡：到期时间、可选发放时间），保持向后兼容——旧字段保留，Renderer 在新字段缺失时回退到仅显示到期时间。
- **样式**：在设置页 Shadow DOM 内使用 Tailwind 工具类（遵循 `docs/architecture/renderer-settings-styling.md`），适配明暗主题；原账号页专用 CSS 中仅删除本次改造产生的孤儿规则。
- **本地化**：新增文案同时提供中英文。
- **文档**：更新 `docs/product/codex-accounts.md` 中「账号列表」「重置卡」两节以反映新样式。

## Testing Decisions

- 好的测试只检验外部行为：给定额度快照与当前时间，页面呈现出哪些窗口行、百分比、节奏标记位置与颜色、剩余时间文本、重置卡横条；不检验内部函数调用顺序或 DOM 细节以外的实现。
- **节奏标记与窗口行投影**：纯函数单元测试，覆盖 5h/7d/周/月/未知窗口、已用 <5%、刚好超过/未超过节奏 3 个百分点、重置时间已过、剩余口径镜像。
- **渲染**：沿用现有账号页额度测试的假 DOM 写法（先例：`packages/renderer-extension/test/settings/accounts-usage.test.ts`、`accounts-reset-time.test.ts`），检验窗口行结构、缺失窗口不补 0、重置卡有/无发放时间两种呈现、无重置卡时不渲染区域。
- **契约与解析**：先例 `packages/shared-contracts/test/thread-usage.test.ts`、`packages/protocol-core/test/codex-native-usage.test.ts`，覆盖重置卡新字段的解析、缺失与异常值。
- **人工验证**：启动 Codex Connect，打开「设置 → 账号」截图，与参考截图对照；分别检查浅色/深色主题与窄窗口。

## Out of Scope

- 预测性额度提醒（铃铛按钮）与系统通知。
- 订阅登记与续费日期管理（日历按钮）。
- 显示顺序、可见性等额度显示偏好设置（齿轮按钮）。
- Composer 额度药丸与弹层的改版。
- 新增任何 Harness 的额度数据来源（如 Qoder、Kiro 的账号级额度）。
- 使用或消耗 Codex 重置卡。
