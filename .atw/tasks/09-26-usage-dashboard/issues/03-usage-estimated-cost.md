# 03 — Estimated Cost 计价

**What to build:** 用量页在 Token 总数下方显示所选范围的费用；价格每天自动更新，离线时用内置价格；没有价格的模型不报错、费用记 0。

**Blocked by:** 01
**Status:** ready-for-agent
**Impl:** ready

## Acceptance criteria

- [ ] 价格来源回退顺序：24 小时磁盘缓存 → 远程 LiteLLM 价格表 → 过期缓存 → 内置快照；手工覆盖始终优先
- [ ] 模型名匹配支持精确、别名、去后缀、去厂商前缀、最长子串兜底
- [ ] 费用公式按输入/输出/缓存读/缓存写/推理分项计价，推理已含在输出中的 Harness 不重复计；有自报费用时优先
- [ ] 费用在查询时计算，价格更新后历史费用随之更新
- [ ] 计价有纯函数测试；Host 请求层测试断言费用
- [ ] 界面不额外标注「按 API 价格估算」；产品文档同步更新
