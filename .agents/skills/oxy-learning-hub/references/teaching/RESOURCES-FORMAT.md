# RESOURCES.md 格式

`RESOURCES.md` 保存本主题经过筛选的可信来源，以及用户可以检验真实经验的社区或
实践环境。

## 模板

```markdown
# {主题} Resources

## Knowledge

- `R001` [来源名称](URL)
  覆盖：{讲什么}。
  支持：{哪些关键事实或概念}。
  使用于：{已经实际引用该来源的课程或参考资料路径}。
  信任说明：{为何可信或有什么限制}。

## Wisdom

- [社区或实践环境](URL 或地点)
  用于：{适合检验什么真实问题}。

## Gaps

- {当前 Mission 需要、但还没有可靠来源支持的内容}
```

## 规则

- 优先原始文档、规范、论文、源码、公认专家和严格审核的社区。
- 每条来源使用稳定编号，并说明覆盖范围、支持的结论和实际使用位置。
- 尚未被课程使用的候选来源写 `状态：候选，尚未使用`，不虚构 `使用于` 路径；
  首次实际引用后再替换为真实路径。
- 课程正文使用本课 `[S1]` 锚点就近引用，`RESOURCES.md` 使用 `R001` 等稳定编号
  维护跨课程追踪；两者通过来源标题或 URL 对应。
- 搜索结果只是发现线索，重要事实回到原始来源核对。
- 已证明错误、浅薄或偏离 Mission 的来源直接移除。
- 用户不希望加入社区时在这里或 `NOTES.md` 记录，后续不重复建议。
- 五个高质量来源优于三十个普通来源。
