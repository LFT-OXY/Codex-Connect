# 学习记录格式

学习记录位于 `learning-records/`，使用连续编号：

```text
0001-topic.md
0002-next-topic.md
```

它记录会影响后续教学的非平凡理解，而不是课程活动日志。

## 模板

```markdown
# {已经建立的理解}

{1～3 句话说明用户掌握了什么、证据是什么，以及它如何改变下一步教学。}
```

可选内容只有在确实需要时加入：

- YAML frontmatter：`status: active | superseded by LR-NNNN`
- `Evidence`：用户如何展示理解
- `Implications`：它解锁或排除了哪些后续课程

## 写入条件

只有以下情况才创建：

1. 用户正确解释或应用了非平凡概念；
2. 用户说明已有知识，并提供了足以判断深度的证据；
3. 一个误解被纠正；
4. Mission 因学习结果而改变。

以下情况不创建：

- 课程只是讲过某个内容；
- 用户只点击了完成按钮；
- 术语定义已经由 `GLOSSARY.md` 充分记录；
- 单纯的会话或活动日志。

后来的理解推翻旧记录时，标记旧记录被新编号取代，不删除学习演变历史。
