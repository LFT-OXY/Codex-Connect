# GLOSSARY.md 格式

`GLOSSARY.md` 是教学工作区的统一语言。只有用户已经理解并能正确使用的术语才进入
这里；它不是提前灌输给用户的字典。

## 模板

```markdown
# {主题} Glossary

{一到两句话说明术语表覆盖的主题范围。}

## {自然类别；术语较少时可使用 Terms}

**术语**：
一到两句话的紧凑定义。
_避免使用_：容易造成混淆的别名
```

## 规则

- 只有用户展示理解后才新增术语。
- 多个词表达同一概念时选定一个首选词，其他词列为避免使用或别名。
- 定义说明“它是什么”，控制在一到两句话。
- 定义新术语时优先使用词汇表中已经稳定的术语，让概念在同一语言体系中组合。
- 术语形成自然类别时使用二级标题分组，例如“协议角色”“凭据”“安全机制”；
  数量较少且彼此紧密时可以保持平铺。
- 后续课程、练习和学习记录统一使用术语表中的语言。
- 术语在领域中含义模糊时，明确本工作区采用的定义。
- 用户理解深化后原地修订定义，不保留已经错误的旧定义。
