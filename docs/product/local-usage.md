# 用量统计

「设置 → 用量」统计本机各 Harness 原生会话记录中的 Local Usage，包括直接在终端运行 CLI 产生的用量。数据来源与解析归属见 [ADR-0001](../adr/0001-local-usage-from-native-session-records.md)、[ADR-0002](../adr/0002-native-usage-parsing-lives-in-adapters.md)。当前只接入 Claude Code；Codex、Pi、oh-my-pi、Estimated Cost、统计块、项目用量与首次读取进度尚未实现。

## 页面

- 打开「用量」页时设置对话框放大到接近整个窗口（四周各留 16px），内容区最宽 1400px；切到其他设置页后恢复原尺寸。窄窗口（≤720px）与其他页面一样占满窗口。
- 周期：日、周、月、总计、自定义，默认「周」。周从周一开始；「总计」为 23 个月前的当月 1 日到今天（最近 24 个月）；自定义选择起止日期后点「应用」生效，开始日期不能晚于结束日期、跨度不超过 3660 天。所有日期按本机时区划分。
- 中央大号数字是所选范围的 Token 总数，悬停可读完整数值；其下是范围起止日期。
- 按 Harness 的占比横条与卡片：「全部」卡片显示 100% 与该范围内涉及的模型数；每个有用量的 Harness 一张卡片，显示占比（两位小数）与模型数，按用量从高到低排列。范围内没有用量的 Harness 不出现。
- 每日明细：日期、总计、输入、输出、缓存、推理、对话数，只列出有 Token 或对话的日期（跨零点时可能出现只有对话、总计为 0 的日期），按日期倒序。「缓存」列只含缓存读。
- 大数字以 K/M/B 缩写，最多两位小数（如 `12.35K`、`6.04B`）；四舍五入到下一级时进位（`999,999` 显示为 `1M`）。
- 范围内没有任何用量时只显示总数 0 与「该周期内没有用量」。
- 页面只显示聚合数字，不显示也不传输任何消息正文、会话 ID 或工作目录。
- 本地 Host 不支持该查询时显示「本地 Host 不支持用量统计」，读取失败时显示可重试的失败提示。页面始终查询本地 Host，与当前 Composer 连接的 Host 无关。

## 口径

- Token 总数 = 输入（不含缓存）+ 缓存读 + 缓存写 + 输出 + 推理，不重复计。
- 对话数按各 Harness 自身口径计，不可跨 Harness 比较。Claude Code 计主会话中用户输入的消息（字符串内容或含文本块），不计工具结果和子代理中的消息。
- Claude Code：读取 `$CLAUDE_CONFIG_DIR/projects`（默认 `~/.claude/projects`）下的主会话 `*.jsonl` 与 `<session>/subagents/*.jsonl`。同一次模型回复在记录中会重复写入多行（子代理记录还会先写入未完成的用量），按 `message.id + requestId` 只计一次，取最后一行的用量。最后一行没有 `stop_reason` 的回复可能仍在生成（工具结果可能先于最终用量写入），在该文件最近 1 小时内有写入时等下次读取再计；文件闲置超过 1 小时则按最后一行计入（被中断的回复）。Claude Code 不单独记录思考 Token，推理列为 0，思考量包含在输出中。

## 读取与缓存

- 打开页面时 Host 先增量读取新增记录再返回；切换周期只用已读取的数据，不重新读取；「刷新」按钮强制重新增量读取。关闭设置后不再读取，没有后台定时读取。
- 首次读取全部历史，之后按文件只读取新增的完整行；文件被替换或截断时从头重读，已计过的记录不会重复计入。同一时刻只有一次读取，并发请求共享它。
- Host 把游标、已计记录的短哈希和 UTC 半小时聚合桶（Harness × Provider × Model × 工作目录，工作目录供后续项目用量使用）保存在 `${CODEXHOST_DATA_DIR:-~/.codexhost}/usage/local-usage.json`，查询时按请求的时区把桶归日。原生记录被 Harness 清理后，已统计的用量仍保留。文件损坏时从原生记录重建。
- 某个 Harness 读取失败或返回不合规记录（如多出正文字段）时整批不计，保留它上次的统计与游标，不影响其他 Harness；失败状态暂未在页面显示。
- 读取进行中切换周期时，查询等待本次读取完成后再返回，不会先显示旧数据。
- 用量读取是 Adapter 的可选能力 `nativeUsage.read(cursor)`，未安装或未实现该能力的 Harness 不参与统计。
